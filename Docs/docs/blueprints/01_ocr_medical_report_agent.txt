### What This Module Does
The OCR module takes **medical documents** (images/PDFs of lab reports, prescriptions, discharge summaries) and:
1. Extracts text from images/PDFs using multiple OCR engines
2. Parses the raw text into **structured data** (test name, value, unit, range, flag)
3. Validates the parsed data against **clinical reference ranges**
4. Produces a structured JSON output that feeds into the agent pipeline

### How OCR Feeds Into the Pipeline
The `agent_feed` field from OCR output can be injected into the LangGraph `DiagnosticState`:
- `vitals_update` → merges with `features` in `node_predict()` (updates `platelet_low`, `wbc_abnormal`)
- `suggested_conditions` → boosted in `node_differential()` voting
- `abnormal_flags` → added to `node_emergency()` red-flag detection
