### A. MongoDB Chat Persistence

What's missing: Wiring to chatbot_routes.py

How to wire:
  1. In chatbot_routes.py, after generating answer:

### B. Doctor Feedback Model

```
New SQLAlchemy model in database/postgres/models.py:

class DoctorFeedback(db.Model):
    __tablename__ = 'doctor_feedback'
    
    id = Integer, primary_key
    case_id = Integer, ForeignKey('cases.id')
    doctor_id = Integer, ForeignKey('users.id')
    
    # Feedback on AI diagnosis
    ai_diagnosis_correct = Boolean  (did AI get it right?)
    corrected_diagnosis = String    (if wrong, what's the right one?)
    severity_correct = Boolean
    corrected_severity = String
    
    # Feedback on recommendations
    medications_appropriate = Boolean
    medication_notes = Text
    tests_appropriate = Boolean
    test_notes = Text
    
    # Overall
    overall_rating = Integer (1-5)
    clinical_notes = Text
    
    created_at = DateTime
```
