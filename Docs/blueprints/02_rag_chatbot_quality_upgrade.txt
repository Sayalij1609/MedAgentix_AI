### Problem With Current RAG

The current [rag_system.py](file:///c:/docs/Downloads/My_Projects/MedAgentixAI_New_Version/MedAgentix_AI/rag/rag_system.py) has fundamental quality issues:

1. **TF-IDF is keyword-based, not semantic.** If user asks "What causes chest tightness?" but chunks use "cardiac syndrome", TF-IDF won't match because the WORDS don't overlap. Semantic models understand that "chest tightness" ≈ "cardiac syndrome."

2. **No conversation memory.** Each query is independent. If user asks "What about treatment?" after "Tell me about Pneumonia", the RAG has no idea "treatment" refers to Pneumonia.

3. **Full dependence on Gemini API.** If API is down or key expires, the fallback ([_template_answer()](file:///c:/docs/Downloads/My_Projects/MedAgentixAI_New_Version/MedAgentix_AI/rag/rag_system.py#L372)) just dumps raw chunks.

4. **No evidence passages.** The `sources` returned to frontend only contain disease/category — not the actual text that supports the answer.

### What to Build

#### A. PubMedBERT Embeddings (`embeddings/pubmedbert_embed.py`)

```
Purpose: Convert medical text into 768-dimensional vectors that 
understand medical semantics.

Model: "microsoft/BiomedNLP-BiomedBERT-base-uncased-abstract"
  - Trained on 16.5M PubMed abstracts
  - Understands medical terminology relationships
  - "chest tightness" and "cardiac symptoms" → similar vectors

How it works:
  1. Load PubMedBERT model + tokenizer from HuggingFace
  2. encode(text) → tokenize → forward pass → mean pool → 768-dim vector
  3. encode_batch(texts) → same but for lists (faster for KB building)

Input:  "Pneumonia causes fever, cough, and breathlessness"
Output: numpy array of shape (768,) — a dense vector

This replaces TF-IDF vectorization in knowledge_base.py
```

#### B. FAISS Vector Store (`retriever.py`)

```
Purpose: Ultra-fast similarity search over 6,700+ medical chunks.

What is FAISS?
  Facebook AI Similarity Search — a library that indexes vectors
  and finds nearest neighbors in milliseconds, even over millions
  of vectors.

How it works:
  1. BUILDING (one-time, during knowledge_base.py):
     - Take all 6,700 chunks
     - Convert each to 768-dim vector using PubMedBERT
     - Build a FAISS IndexFlatIP index (Inner Product = cosine sim)
     - Save index to disk as faiss_index.bin

  2. RETRIEVAL (every query):
     - Convert user question to 768-dim vector using same PubMedBERT
     - Search FAISS index: faiss_index.search(query_vector, top_k=5)
     - Returns top-5 chunk indices + similarity scores
     - Look up chunk text + metadata from stored arrays

Why better than TF-IDF:
  TF-IDF: "heart attack symptoms" → matches "heart", "attack", "symptoms"
  FAISS+PubMedBERT: "heart attack symptoms" → matches "acute MI 
  presentation", "cardiac event signs", "myocardial infarction clinical 
  features" (semantic understanding)

Performance: 
  TF-IDF search over 6,700 chunks: ~50ms
  FAISS search over 6,700 chunks: ~2ms (25x faster + smarter)
```

#### C. Conversation Memory (using MongoDB)

```
Purpose: Remember previous messages in a chat session so multi-turn
conversations work.

How it works:
  1. Each chat session gets a session_id (UUID)
  2. Every message (user + assistant) is stored in MongoDB:
     Collection: "chat_sessions"
     Document: {
       session_id: "abc-123",
       messages: [
         {role: "user", content: "Tell me about Pneumonia", timestamp: ...},
         {role: "assistant", content: "Pneumonia is...", timestamp: ...},
         {role: "user", content: "What about treatment?", timestamp: ...}
       ],
       created_at: ...,
       last_active: ...
     }

  3. Before each query, the system loads the last N messages (context window)
  4. These are prepended to the Gemini/LLM prompt:

     Previous conversation:
       User: Tell me about Pneumonia
       Assistant: Pneumonia is an infection of the lungs...
       User: What about treatment?
     
     → Now the RAG knows "treatment" refers to "Pneumonia"

  5. Context window: Last 5-10 messages (to avoid token overflow)
```

##### Step 1: Intent Detection (add to `rag_system.py`)

A lightweight keyword classifier that determines what type of message the user sent:

```python
# Symptom-indicating keywords and phrases
SYMPTOM_TRIGGER_KEYWORDS = [
    # Direct symptom words
    "fever", "cough", "pain", "headache", "vomiting", "nausea",
    "breathing", "breathless", "rash", "fatigue", "tired",
    "dizzy", "dizziness", "bleeding", "swelling", "weakness",
    "chest", "stomach", "joint", "back pain", "sore throat",
    "diarrhea", "constipation", "itching", "weight loss",
    "palpitations", "seizure", "confusion", "blurred vision",
    
    # Symptom-reporting phrases
    "i have", "i feel", "i am having", "i've been",
    "suffering from", "experiencing", "diagnosed with",
    "my symptoms", "symptoms include", "started feeling",
    "woke up with", "been having", "getting worse",
]

GREETING_KEYWORDS = ["hello", "hi", "hey", "greetings", 
                     "good morning", "good afternoon", "good evening"]

PLATFORM_KEYWORDS = ["medagentix", "how does", "how to use", "pdf",
                     "prescription", "shap", "explainability", 
                     "agent", "pipeline", "what is this"]

def _detect_intent(self, question):
    """
    Classify user message intent to determine processing path.
    
    Returns:
        "greeting"        → Template greeting response
        "platform_help"   → Template platform explanation
        "symptom_report"  → Trigger RAG + Pipeline (THE KEY PATH)
        "knowledge_query" → RAG retrieval only
    """
    q = question.lower().strip()
    
    # Check greetings first (shortest messages)
    if any(greet in q for greet in GREETING_KEYWORDS) and len(q.split()) < 5:
        return "greeting"
    
    # Check platform help queries
    if any(kw in q for kw in PLATFORM_KEYWORDS):
        return "platform_help"
    
    # Check for symptom reporting (the important one)
    symptom_score = sum(1 for kw in SYMPTOM_TRIGGER_KEYWORDS if kw in q)
    if symptom_score >= 1:  # At least 1 symptom keyword found
        return "symptom_report"
    
    # Default: general medical knowledge query
    return "knowledge_query"
```

```python
def _run_diagnostic_pipeline(self, question, age=40, gender="Male"):
    """
    Run the full LangGraph diagnostic pipeline on symptom text.
    
    This calls the SAME pipeline that the case/intake API uses,
    but triggered from the chatbot instead of the form.
    
    Args:
        question: User's symptom description text
        age: Patient age (default 40 if not provided)
        gender: Patient gender (default "Male" if not provided)
    
    Returns:
        dict: Full pipeline state including final_diagnosis
    """
    try:
        from agents.orchestrator.langgraph_workflow import run_pipeline
        
        state = run_pipeline({
            "patient_text": question,
            "patient_age": age,
            "patient_gender": gender,
            # Default vitals (since chatbot doesn't collect them)
            "blood_pressure": "Normal",
            "blood_pressure_reading": "120/80",
            "cholesterol": 180,
            "heart_rate": 80,
            "oxygen_level": 98,
            "body_temperature": 98.6,
            "lifestyle_factors": [],
            "medical_history": [],
            "symptom_durations": [],
        })
        
        return state.get("final_diagnosis", {})
    
    except Exception as e:
        print(f"[RAG] Pipeline execution failed: {e}")
        return {}  # Graceful fallback — RAG still works without pipeline
```

```python
def _build_integrated_prompt(self, question, pipeline_result, rag_chunks):
    """
    Build a Gemini prompt that combines pipeline diagnosis + KB knowledge.
    
    This is the KEY innovation — the LLM synthesizes the structured
    diagnostic output with retrieved medical context into a natural,
    comprehensive clinical response.
    """
    
    # Format pipeline results
    pipeline_section = ""
    if pipeline_result:
        disease = pipeline_result.get('final_disease', 'Unknown')
        confidence = pipeline_result.get('final_confidence', 0)
        severity = pipeline_result.get('severity', 'N/A')
        source = pipeline_result.get('diagnosis_source', 'N/A')
        reasoning = pipeline_result.get('reasoning', '')
        
        # Tests
        tests = pipeline_result.get('recommended_tests', [])
        test_names = [t.get('test', t) if isinstance(t, dict) else str(t) 
                      for t in tests[:5]]
        
        # Medications  
        meds = pipeline_result.get('recommended_medications', [])
        med_info = []
        for m in meds[:3]:
            if isinstance(m, dict):
                med_info.append(f"{m.get('drug', 'N/A')} {m.get('dosage', '')}")
            else:
                med_info.append(str(m))
        
        # Risk
        risk_level = pipeline_result.get('risk_level', 'N/A')
        risk_factors = pipeline_result.get('risk_factors', [])
        
        # SHAP
        shap = pipeline_result.get('shap_explanation', {})
        top_drivers = []
        if shap and shap.get('top_positive_factors'):
            for f in shap['top_positive_factors'][:3]:
                top_drivers.append(
                    f"{f.get('display_name', f.get('feature', '?'))}: "
                    f"{f.get('shap_value', 0):+.3f}"
                )
        
        # Emergency
        emergency = pipeline_result.get('emergency_status', {})
        is_emergency = emergency.get('is_emergency', False)
        
        pipeline_section = f"""
=== AI DIAGNOSTIC PIPELINE RESULTS ===
(Generated by MedAgentix multi-agent system: Symptom Agent → 
Differential Agent → Risk Agent → Temporal Agent → Emergency Agent → 
Prediction Engine → Recommendation Agent → Supervisor)

Primary Diagnosis: {disease}
Confidence: {confidence:.1%} [{pipeline_result.get('confidence_level', 'N/A').upper()}]
Severity: {severity}
Diagnosis Source: {source}
Reasoning: {reasoning}
{'🚨 EMERGENCY DETECTED — Immediate medical attention required' if is_emergency else ''}

Risk Level: {risk_level}
Risk Factors: {', '.join(risk_factors[:5]) if risk_factors else 'None identified'}

Recommended Tests: {', '.join(test_names) if test_names else 'General workup'}
Suggested Medications: {', '.join(med_info) if med_info else 'Consult physician'}

Key Diagnostic Drivers (SHAP): {'; '.join(top_drivers) if top_drivers else 'N/A'}
"""
    
    # Format RAG knowledge chunks
    rag_section = ""
    for i, chunk in enumerate(rag_chunks[:3]):
        rag_section += f"\n--- Knowledge Source {i+1} "
        rag_section += f"(Relevance: {chunk.get('similarity_score', 0):.2f}) ---\n"
        rag_section += chunk.get('chunk', '') + "\n"
    
    # Build the unified prompt
    prompt = f"""You are the MedAgentix AI Clinical Assistant.

You have TWO sources of information:
1. DIAGNOSTIC PIPELINE RESULTS — Our multi-agent AI system has analyzed the 
   patient's symptoms through 8 specialized agents and produced a diagnosis.
2. MEDICAL KNOWLEDGE BASE — Relevant medical knowledge retrieved from our 
   database of 6,700+ disease records.

Your job is to synthesize BOTH sources into one clear, professional, 
compassionate clinical response.

IMPORTANT RULES:
- Lead with the pipeline diagnosis (the personalized assessment)
- Support it with medical knowledge from the KB
- Include recommended tests and medications
- Explain WHY the AI reached this conclusion (SHAP drivers)
- If confidence is below 70%, emphasize the need for specialist consultation
- If emergency is detected, LEAD with emergency instructions
- Always end with the medical disclaimer
- Use clear headings and bullet points for readability
{pipeline_section}
=== RETRIEVED MEDICAL KNOWLEDGE ===
{rag_section if rag_section else 'No specific knowledge chunks retrieved.'}

=== PATIENT MESSAGE ===
{question}

=== YOUR RESPONSE ===
Provide a comprehensive, structured clinical response:"""
    
    return prompt
```

##### Step 4: Updated `query()` Method (modify in `rag_system.py`)

The main entry point now routes based on intent:

```python
def query(self, question, top_k=5, category_filter=None, 
          severity_filter=None, patient_age=40, patient_gender="Male"):
    """
    Main RAG pipeline — now with diagnostic pipeline integration.
    
    Flow:
      1. Detect intent
      2. If symptom_report → run BOTH RAG retrieval AND diagnostic pipeline
      3. If knowledge_query → run RAG retrieval only
      4. Generate unified answer via Gemini
    """
    intent = self._detect_intent(question)
    
    # Always retrieve from knowledge base (for all intents except greetings)
    retrieved_chunks = []
    if intent not in ("greeting", "platform_help"):
        retrieved_chunks = self.retrieve(
            question, top_k=top_k,
            category_filter=category_filter,
            severity_filter=severity_filter
        )
    
    # ── SYMPTOM REPORT → Run diagnostic pipeline ──
    pipeline_result = {}
    if intent == "symptom_report":
        pipeline_result = self._run_diagnostic_pipeline(
            question, age=patient_age, gender=patient_gender
        )
    
    # ── Generate answer ──
    if intent == "symptom_report" and pipeline_result:
        # INTEGRATED MODE: Pipeline + RAG + Gemini
        prompt = self._build_integrated_prompt(
            question, pipeline_result, retrieved_chunks
        )
        if self.gemini_model:
            try:
                response = self.gemini_model.generate_content(prompt)
                answer = response.text
            except Exception:
                answer = self._format_pipeline_fallback(pipeline_result)
        else:
            answer = self._format_pipeline_fallback(pipeline_result)
    else:
        # STANDARD MODE: RAG only (knowledge queries, greetings, etc.)
        answer = self.generate_answer(question, retrieved_chunks)
    
    return answer, retrieved_chunks, pipeline_result
```

```python
def _format_pipeline_fallback(self, pipeline_result):
    """Format pipeline output as readable text when Gemini is unavailable."""
    disease = pipeline_result.get('final_disease', 'Unknown')
    confidence = pipeline_result.get('final_confidence', 0)
    severity = pipeline_result.get('severity', 'N/A')
    
    tests = pipeline_result.get('recommended_tests', [])
    test_names = [t.get('test', str(t)) if isinstance(t, dict) else str(t)
                  for t in tests[:5]]
    
    meds = pipeline_result.get('recommended_medications', [])
    med_lines = []
    for m in meds[:3]:
        if isinstance(m, dict):
            med_lines.append(f"• {m.get('drug', '?')} — {m.get('dosage', '?')}")
    
    answer = f"""🏥 **MedAgentix AI Diagnostic Assessment**

**Primary Diagnosis:** {disease}
**Confidence:** {confidence:.1%}
**Severity:** {severity}
**Risk Level:** {pipeline_result.get('risk_level', 'N/A')}

**Recommended Diagnostic Tests:**
{chr(10).join('• ' + t for t in test_names) if test_names else '• General medical workup'}

**Suggested Medications:**
{chr(10).join(med_lines) if med_lines else '• Consult physician for prescription'}

**Reasoning:** {pipeline_result.get('reasoning', 'N/A')}

---
⚠️ *Disclaimer: This is an AI-generated diagnostic assessment for 
informational purposes only. Always consult a qualified healthcare 
professional before starting any treatment.*"""
    
    return answer
```

#### Design Decision: Auto-trigger vs Confirm-first

| Approach | How it works | Pros | Cons |
|----------|-------------|------|------|
| **Auto-trigger** | Detect symptoms → run pipeline immediately | Seamless UX, instant results | Pipeline takes 3-10s, may false-trigger |
| **Confirm-first** | Detect symptoms → ask "Run diagnostic?" → then run | User controls processing, fewer false triggers | Extra interaction step |
| **Hybrid (recommended)** | Auto-trigger for clear symptom reports (score ≥ 2 keywords), confirm for ambiguous (score = 1) | Best of both worlds | Slightly more logic |
