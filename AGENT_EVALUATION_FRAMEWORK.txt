1. OVERVIEW & EVALUATION DIMENSIONS
====================================================================================================

Evaluating a multi-agent medical AI system requires assessment across 5 key dimensions:

  1. TASK-LEVEL ACCURACY       — Does each agent produce correct outputs?
  2. CLINICAL SAFETY           — Does the system never miss a dangerous condition?
  3. LATENCY & THROUGHPUT      — Is the system fast enough for clinical use?
  4. ROBUSTNESS                — Does the system handle noisy/incomplete input gracefully?
  5. END-TO-END PIPELINE       — Do all agents work well together as a unified system?


----------------------------------------------------------------------------------------------------
1.1  DIMENSION A: TASK-LEVEL ACCURACY METRICS
----------------------------------------------------------------------------------------------------

  Standard ML metrics — measures whether each agent produces the correct output for a given input.
  Examples: Accuracy, Precision, Recall, F1-Score, Top-K Accuracy, MRR, NDCG.


----------------------------------------------------------------------------------------------------
1.2  DIMENSION B: CLINICAL SAFETY METRICS
----------------------------------------------------------------------------------------------------

  Medical-specific metrics — measures whether the system never misses a dangerous condition,
  even if it occasionally over-alerts. In medicine, false negatives (missing a real disease) are
  far more dangerous than false positives (flagging a harmless condition).


----------------------------------------------------------------------------------------------------
1.3  DIMENSION C: LATENCY & PERFORMANCE METRICS
----------------------------------------------------------------------------------------------------

  Engineering metrics — measures whether the system responds fast enough for clinical use.
  Target: < 5 seconds for the full pipeline end-to-end.


----------------------------------------------------------------------------------------------------
1.4  DIMENSION D: ROBUSTNESS & STRESS TESTING
----------------------------------------------------------------------------------------------------

  Reliability metrics — measures whether the system degrades gracefully on noisy, incomplete,
  or adversarial inputs rather than crashing or hallucinating.


----------------------------------------------------------------------------------------------------
1.5  DIMENSION E: END-TO-END PIPELINE METRICS
----------------------------------------------------------------------------------------------------

  System-level metrics — measures whether the full pipeline (all agents working together)
  produces coherent, clinically sound results.

AGENT 1: SYMPTOM AGENT (NER + Severity + Normalization)
----------------------------------------------------------------------------------------------------

This agent has 3 sub-tasks, each requiring different metrics:

  Sub-Task 1A: Symptom NER (Named Entity Recognition)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Token-Level Precision         | TP / (TP + FP)                | Of predicted symptom tokens, how many    |
  |                               |                               | are correct?                             |
  | Token-Level Recall            | TP / (TP + FN)                | Of actual symptom tokens, how many       |
  |                               |                               | were found?                              |
  | Token-Level F1                | 2 x (P x R) / (P + R)        | Harmonic mean — balanced extraction      |
  |                               |                               | quality                                  |
  | Entity-Level Exact Match      | Correct entities / Total      | Full symptom span match (strict)         |
  | Entity-Level Partial Match    | Overlapping entities / Total  | Partial symptom span overlap (lenient)   |
  +-------------------------------+-------------------------------+------------------------------------------+

  How to Evaluate:
    Test Set     : 200+ sentences with gold-standard BIO-tagged symptom annotations
    Tool         : seqeval library (standard NER evaluation)
    Expected     : Token F1 > 90%, Entity Exact Match > 85%


  Sub-Task 1B: Severity Classification (4-class: Mild / Moderate / Severe / Critical)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Accuracy                      | Correct / Total               | Overall correctness                      |
  | Macro F1                      | Average F1 across 4 classes   | Balanced across Mild/Moderate/Severe/    |
  |                               |                               | Critical                                 |
  | Weighted F1                   | Class-size-weighted F1        | Accounts for class imbalance             |
  | Per-Class Recall              | Per-class TP / (TP + FN)      | Detection rate per severity level        |
  | Confusion Matrix              | 4x4 matrix                    | Which severities get confused            |
  +-------------------------------+-------------------------------+------------------------------------------+

  *** CRITICAL SAFETY METRIC ***
  Severe/Critical Recall MUST be > 95% — never classify a "Severe" symptom as "Mild"


  Sub-Task 1C: Symptom Normalization
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Top-1 Normalization Accuracy  | Correct canonical / Total     | Exact match to correct standard term     |
  | Top-3 Normalization Accuracy  | Correct in top-3 / Total      | Correct term in top 3 candidates         |
  | Mean Reciprocal Rank (MRR)    | 1/rank of correct answer      | Quality of ranking                       |
  | Synonym Coverage              | Mapped synonyms / Total       | How many colloquial variations handled   |
  +-------------------------------+-------------------------------+------------------------------------------+

AGENT 2: TRIAGE AGENT (Rule-Based 3-Tier Classification: GREEN / YELLOW / RED)
----------------------------------------------------------------------------------------------------

  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Classification Accuracy       | Correct tier / Total          | Overall tier assignment correctness      |
  | RED Sensitivity (Recall)      | True RED / (True RED +        | CRITICAL: Never miss an emergency        |
  |                               | Missed RED)                   |                                          |
  | RED Specificity               | True non-RED / (True non-RED  | Don't over-triage mild cases to RED      |
  |                               | + False RED)                  |                                          |
  | GREEN Precision               | True GREEN / All predicted    | Don't send emergencies to self-care      |
  |                               | GREEN                         |                                          |
  | False Negative Rate (RED)     | Missed RED / Total RED        | MUST be 0% — no missed emergencies       |
  | Over-Triage Rate              | GREEN/YELLOW sent to RED      | Acceptable if < 15% (safety margin)      |
  |                               | / Total                       |                                          |
  | Under-Triage Rate             | RED cases sent to GREEN/      | MUST be 0% — absolutely unacceptable     |
  |                               | YELLOW / Total                |                                          |
  | Cohen's Kappa                 | Agreement beyond chance       | Agreement vs. expert clinician labels    |
  +-------------------------------+-------------------------------+------------------------------------------+

  How to Evaluate:
    Test Set       : 500+ cases with expert-labeled triage tiers (GREEN/YELLOW/RED)
    Include        : 100+ known RED-flag emergency scenarios
    Include        : 100+ known GREEN mild/common illness scenarios
    Include        : 100+ borderline YELLOW cases
    Critical Rule  : Under-triage rate MUST be 0% (no emergency ever classified as mild)

AGENT 3: DIFFERENTIAL DIAGNOSIS AGENT (721-Class Disease Ranking)
----------------------------------------------------------------------------------------------------

  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Top-1 Accuracy                | Correct #1 / Total            | Exact match of primary diagnosis         |
  | Top-3 Accuracy                | Correct in top-3 / Total      | Correct disease in top 3 candidates      |
  | Top-5 Accuracy                | Correct in top-5 / Total      | Correct disease in top 5 candidates      |
  | Mean Reciprocal Rank (MRR)    | Mean(1/rank of correct)       | Average ranking quality                  |
  | Weighted F1                   | Class-weighted F1             | Balanced F1 for disease prevalence       |
  | Macro F1                      | Unweighted average F1         | Performance on rare diseases (important!)|
  | NDCG@5                        | Normalized Discounted         | Quality of top-5 ranking order           |
  |                               | Cumulative Gain               |                                          |
  | Per-Disease-Group Accuracy    | Accuracy within disease       | Cardiac vs. respiratory vs. GI etc.      |
  |                               | families                      |                                          |
  +-------------------------------+-------------------------------+------------------------------------------+

  How to Evaluate:
    Test Set       : 49,365 records (already split from training)
    Stratified by  : Disease family, symptom count, rare vs. common diseases
    Key Focus      : Macro F1 (ensures rare diseases are not ignored)
    Expected       : Top-1 > 80%, Top-3 > 93%, Top-5 > 96%

AGENT 6: EMERGENCY & CRITICAL CARE AGENT
----------------------------------------------------------------------------------------------------

  +-------------------------------+-------------------------------+------------------------------------------+
  | Metric                        | Formula                       | What It Measures                         |
  +-------------------------------+-------------------------------+------------------------------------------+
  | Triage Accuracy               | Correct ESI level / Total     | Overall ESI triage correctness           |

  How to Evaluate:

3. END-TO-END PIPELINE EVALUATION
====================================================================================================

These metrics measure the full pipeline (all agents working together as a unified system):

  +-------------------------------+--------------------------------------------------------------------+
  | Metric                        | What It Measures                                                   |
  +-------------------------------+--------------------------------------------------------------------+
  | Pipeline Success Rate         | % of inputs that complete the full pipeline without errors          |
  | End-to-End Diagnostic Acc     | Correct final diagnosis / Total test cases                         |
  | End-to-End Top-3 Accuracy     | Correct disease in final top-3 differential                        |
  | Mean Pipeline Latency         | Average time from patient input to final report (seconds)          |
  | P95 Pipeline Latency          | 95th percentile latency (worst-case user experience)               |
  | Agent Error Propagation Rate  | How often an error in one agent causes downstream failures         |
  | Graceful Degradation Rate     | If one agent fails, does the pipeline still produce useful output? |
  | Clinical Concordance          | Agreement between system output and expert clinician diagnosis     |
  +-------------------------------+--------------------------------------------------------------------+

  How to Evaluate:
    Test Set       : 500+ full patient cases with expert-labeled final diagnosis
    Method         : Run full pipeline end-to-end, log per-agent outputs and timings
    Expected       : Pipeline Success Rate > 98%, E2E Top-3 > 93%, Mean Latency < 5s

4. CLINICAL SAFETY EVALUATION (Medical-Specific)
====================================================================================================

This is the most critical evaluation dimension for a medical AI system.
In healthcare, the cost of a missed diagnosis is far greater than the cost of a false alarm.

  +-------------------------------+----------+------------------------------------------------------------+
  | Safety Metric                 | Target   | Rationale                                                  |
  +-------------------------------+----------+------------------------------------------------------------+
  | Emergency Sensitivity         | >= 99%   | Must detect nearly all true emergencies                    |
  | Under-Triage Rate             | 0%       | Never classify a real emergency as non-urgent              |
  | Critical Disease Miss Rate    | < 1%     | Almost never miss a life-threatening condition             |
  | Harmful Recommendation Rate   | 0%       | Never recommend a contraindicated drug                     |
  | False Reassurance Rate        | < 2%     | Rarely tell a sick patient "you're fine"                   |
  | Appropriate Escalation Rate   | > 95%    | When unsure, escalate to physician review                  |
  +-------------------------------+----------+------------------------------------------------------------+

  How to Evaluate:
    Test Set       : 150+ known emergency/critical cases + 100+ known mild cases
    Method         : Track every case where system outputs "safe" or "mild" and cross-check
    Critical Rule  : ANY missed emergency = system failure (zero tolerance)

  +-------------------------------+-------+--------------------------------------------------------------+
  | TOTAL                         | 1,000 |                                                              |
  +-------------------------------+-------+--------------------------------------------------------------+


----------------------------------------------------------------------------------------------------
5.2  Ground Truth Labeling Guidelines
----------------------------------------------------------------------------------------------------

  - Each case should be labeled by 2+ medical professionals.
  - Inter-annotator agreement should be measured (Cohen's Kappa >= 0.75).
  - Disagreements should be resolved by a third reviewer.
  - Labels should include:
      * Primary diagnosis (ground truth disease)
      * Triage tier (GREEN / YELLOW / RED)
      * Risk tier (Low / Medium / High / Critical)
      * Emergency ESI level (1-5)
      * Expected urgency classification

7. DOCUMENTATION TEMPLATE FOR PROJECT REPORT
====================================================================================================

When documenting evaluation results in your project report, use this structure:


----------------------------------------------------------------------------------------------------
7.1  Evaluation Methodology
----------------------------------------------------------------------------------------------------

  - Test set composition (size, categories, ground truth labeling process)
  - Evaluation dimensions (accuracy, safety, latency, robustness, E2E)
  - Tools and libraries used (scikit-learn, seqeval, custom scripts)
  - Ground truth labeling process and inter-annotator agreement


----------------------------------------------------------------------------------------------------
7.2  Per-Agent Results Template
----------------------------------------------------------------------------------------------------

  For each of the 10 agents, document:

    Agent Name: [Name]
    ===================================================
    Task Description    : [What it does]
    Model / Algorithm   : [What powers it]
    Test Set            : [Size and composition]

    Performance Metrics:
    +---------------------------+----------+
    | Metric                    | Score    |
    +---------------------------+----------+
    | Accuracy                  | XX.XX%   |
    | Precision                 | XX.XX%   |
    | Recall                    | XX.XX%   |
    | F1-Score                  | XX.XX%   |
    | [Safety Metric]           | XX.XX%   |
    | Mean Inference Time       | XX ms    |
    +---------------------------+----------+

    Strengths    : [What the agent does well]
    Limitations  : [Known weaknesses or edge cases]
    Future Work  : [Planned improvements]


----------------------------------------------------------------------------------------------------
7.3  End-to-End Pipeline Results
----------------------------------------------------------------------------------------------------

  - Pipeline success rate
  - E2E diagnostic accuracy (Top-1, Top-3, Top-5)
  - Mean pipeline latency and P95 latency
  - Clinical concordance with expert labels
  - Agent error propagation analysis


----------------------------------------------------------------------------------------------------
7.4  Clinical Safety Audit
----------------------------------------------------------------------------------------------------

  - Emergency detection sensitivity
  - Under-triage rate (must be 0%)
  - Critical disease miss rate (must be < 1%)
  - Harmful recommendation rate (must be 0%)
  - False reassurance rate analysis


----------------------------------------------------------------------------------------------------
7.5  Comparison with Baselines
----------------------------------------------------------------------------------------------------

  - Compare against: random baseline, majority-class baseline, single-model baseline
  - Show that the multi-agent system outperforms simpler approaches
  - Statistical significance testing (p-values, confidence intervals)
