1. EXECUTIVE OVERVIEW & SCOPE BOUNDARY
================================================================================
The MedAgentix OCRAgent is an autonomous clinical document perception and reasoning
agent designed to ingest, transcribe, normalize, clinically evaluate, and bridge
unstructured medical documents directly into MedAgentix AI's multi-agent
diagnostic consultation ecosystem.

Key Objectives Achieved:
* Zero Legacy Gemini Dependencies: Completely eliminated Google Gemini cloud API
  calls from the document pipeline, replacing them with a hybrid architecture of
  local on-premise vision models (PaddleOCR), offline medical NER (Bio_ClinicalBERT),
  a deterministic clinical reference interval knowledge base, and low-latency
  clinical reasoning via the Groq API.
* Modular Multi-Agent Integration: Formalized as a standalone agent class
  (`OCRAgent` in `agents/ocr_agent.py`) within the MedAgentix AI agent team.

DOCUMENT SCOPE BOUNDARIES (CRITICAL):
--------------------------------------------------------------------------------
ALLOWED (In-Scope — Textual Clinical Documents):
  [x] Blood and Laboratory Panels (CBC, LFT, KFT, Lipid Profiles, Metabolic/HbA1c)
  [x] Prescriptions (Rx lists, dosages, routes, administration schedules, indications)
  [x] Hospital Discharge Summaries & Consultation Trajectories
  [x] Clinical Consultation & Progress Notes (Chief complaints, recorded vitals)
  [x] Written Radiology & Ultrasound Impressions (Textual radiological findings)

EXCLUDED (Out-of-Scope — Pixel Imaging):
  [ ] Raw pixel imaging modalities such as DICOM X-rays, MRI scans, CT scans, or
      ultrasound cine clips. (These require specialized computer vision segmentation
      and radiological pixel models, distinct from textual document OCR).

2. SUBSYSTEM ARCHITECTURE (5-LAYER PIPELINE)
================================================================================
When a document is submitted (as a PDF or an image: PNG, JPG, WEBP), it traverses
five sequential, fault-tolerant processing layers:

+------------------------------------------------------------------------------+
| LAYER 1: Layout & Character Stream Extraction (PaddleOCR + PyMuPDF)         |
| - Preprocesses multi-page PDFs by rasterizing each page into 300-DPI images. |
| - Runs PP-OCRv6 text detection (DBNet) and recognition (SVTR/LCNet).         |
| - Corrects document orientation via PP-LCNet_x1_0_doc_ori.                   |
| - De-warps curved or unflattened documents using UVDoc.                      |
| - Produces ordered text streams with character-level confidence scores.      |
+------------------------------------------------------------------------------+
                                       |
                                       v
+------------------------------------------------------------------------------+
| LAYER 2: Offline Medical NER & Pre-Correction (Bio_ClinicalBERT)             |
| - Runs emilyalsentzer/Bio_ClinicalBERT locally on CPU/CUDA.                  |
| - Identifies clinical entities: Diseases, Symptoms, Drugs, Dosages, Units.   |
| - Cleans common OCR misspellings and noise without requiring cloud access.   |
| - Serves as an offline fallback if external APIs are unreachable.            |
+------------------------------------------------------------------------------+
                                       |
                                       v
+------------------------------------------------------------------------------+
| LAYER 3: Deterministic Grounding Engine (medical_reference_ranges.py)        |
| - Cross-references all extracted lab biomarkers against 80+ clinical tests.  |
| - Enforces standard medical intervals (e.g., HbA1c 4.0-5.6 %, Creatinine).  |
| - Assigns deterministic flags: NORMAL, HIGH, LOW, CRITICAL_HIGH, CRITICAL_LOW|
| - GUARANTEES zero LLM hallucination on reference ranges and critical alerts. |
+------------------------------------------------------------------------------+
                                       |
                                       v
+------------------------------------------------------------------------------+
| LAYER 4: Multi-Schema Clinical Intelligence (Groq API Synthesis)             |
| - Dynamically analyzes the document according to its true clinical type:     |
|     * Lab Reports: Biomarker tables, organ impact, follow-up advice.         |
|     * Prescriptions: Medication cards, timing, Drug-Drug Interactions (DDI). |
|     * Clinical Notes: Vitals extraction, diagnoses, emergency red flags.     |
|     * Radiology Notes: Modality, anatomical site, findings & impressions.    |
| - Generates dual-perspective summaries:                                      |
|     * Doctor's Note: Concise, technical, differential-ready clinical language|
|     * Patient Guide: Empathetic, accessible, jargon-free explanations.       |
| - Optimized for Groq rate limits (OTPM 1000 limit safe; max_tokens=950).     |
+------------------------------------------------------------------------------+
                                       |
                                       v
+------------------------------------------------------------------------------+
| LAYER 5: Diagnostic State Bridge (LangGraph DiagnosticState Mapping)         |
| - Maps extracted metrics into standard LangGraph parameters:                 |
|     * Demographics (age, gender)                                             |
|     * Vitals (blood_pressure_reading, heart_rate, SpO2, temperature)         |
|     * Biomarkers (cholesterol, glucose/HbA1c)                                |
|     * Medical History & Active Medications                                   |
|     * Synthesized Chief Complaint (patient_text)                             |
| - Integrates with RAG knowledge chunks for evidence retrieval.               |
+------------------------------------------------------------------------------+

4. MEDICAL KNOWLEDGE BASE & GROUNDING ENGINE
================================================================================
To prevent hallucinated laboratory thresholds, `ocr/medical_reference_ranges.py`
defines deterministic bounds for clinical practice:

Panel Examples:
* CBC: Hemoglobin (M: 13.8-17.2, F: 12.1-15.1 g/dL), WBC (4,000-11,000 /uL),
  Platelets (150,000-450,000 /uL).
* Metabolic: HbA1c (Normal: 4.0-5.6%, Pre-diabetes: 5.7-6.4%, Diabetic: >= 6.5%),
  Fasting Blood Glucose (70-99 mg/dL).
* Renal (KFT): Serum Creatinine (M: 0.7-1.3, F: 0.6-1.1 mg/dL), BUN (7-20 mg/dL).
* Hepatic (LFT): ALT (7-56 U/L), AST (10-40 U/L), Total Bilirubin (0.2-1.2 mg/dL).
* Lipids: Total Cholesterol (<200 mg/dL), LDL (<100 mg/dL), HDL (>40 mg/dL),
  Triglycerides (<150 mg/dL).
* Cardiac: Troponin I (<0.04 ng/mL, Critical >0.40 ng/mL), BNP (<100 pg/mL).

Biomarker Evaluation Logic:
  - If value < critical_low  --> CRITICAL_LOW
  - If value < normal_min    --> LOW
  - If value > critical_high --> CRITICAL_HIGH
  - If value > normal_max    --> HIGH
  - Otherwise                --> NORMAL
